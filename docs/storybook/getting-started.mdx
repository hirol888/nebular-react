# Primeiros passos

## Requisitos

- Node.js 22.20+
- React 19.2+
- React DOM 19.2+

## Instalação

```bash
yarn add @nebular-react/core @nebular-react/hooks @nebular-react/styles
```

Para SSR com Next.js:

```bash
yarn add @nebular-react/ssr @nebular-react/next
```

## Provider

`NebularProvider` injeta tema, direção e icon packs.

```tsx
import { NebularProvider, DEFAULT_THEME } from '@nebular-react/styles';
import { DialogProvider, ToastrProvider, WindowProvider } from '@nebular-react/core';

export function AppProviders({ children }: { children: React.ReactNode }) {
  return (
    <NebularProvider theme={DEFAULT_THEME} dir="ltr">
      <WindowProvider>
        <DialogProvider>
          <ToastrProvider>{children}</ToastrProvider>
        </DialogProvider>
      </WindowProvider>
    </NebularProvider>
  );
}
```

Os providers de overlay são necessários apenas para `showDialog`, `showWindow` e
`showToastr`. `Popover`, `Tooltip`, `Menu` e `Select` funcionam sem eles.

## Temas

```tsx
import {
  NebularProvider,
  DEFAULT_THEME,
  COSMIC_THEME,
  CORPORATE_THEME,
  DARK_THEME
} from '@nebular-react/styles';

<NebularProvider theme={DARK_THEME} dir="rtl">
  <App />
</NebularProvider>;
```

## Primeiro componente

```tsx
import { Button, Card, Select } from '@nebular-react/core';

<Card>
  <Card.Header>Usuários</Card.Header>
  <Card.Body>
    <Select
      options={[
        { type: 'option', label: 'Ativo', value: 'active' },
        { type: 'option', label: 'Inativo', value: 'inactive' }
      ]}
      placeholder="Status"
      searchable
      clearable
    />
    <Button status="primary">Filtrar</Button>
  </Card.Body>
</Card>;
```

## Importação

Os pacotes publicam ESM e CJS com declarações separadas:

- `import` → `esm/` + `lib/` (`.d.ts`)
- `require` → `cjs/` + `lib-cjs/` (`.d.cts`)

## Acessibilidade

Sempre forneça nome acessível:

```tsx
<Select aria-label="Status" options={options} />
<DataGrid ariaLabel="Usuários" data={rows} columns={columns} />
```
